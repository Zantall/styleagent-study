# StyleAgent User Study

Image evaluation questionnaire: style consistency, semantic consistency, and aesthetics.

Website: https://zantall.github.io/styleagent-study/

This repository contains only the built frontend. Supabase Free provides the database, image storage, authentication, and backend functions. Response data and administrator credentials are not stored in this repository.

The frontend contains a publishable API key by design. Administrator operations require a verified user and server-side authorization; responses and method mappings are private.
