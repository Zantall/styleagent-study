# StyleAgent User Study

Public image evaluation questionnaire: style consistency, semantic consistency, and aesthetics.

Website: https://zantall.github.io/styleagent-study/

This repository contains only the built frontend. Response data and administrator credentials are not stored in this repository. The application uses a separately managed CloudBase backend with access controls.

The frontend contains a publishable anonymous API key by design. It does not grant access to raw responses, administrator functions, or private configuration.
